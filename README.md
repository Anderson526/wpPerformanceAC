## Descripción

Este plugin ayuda a mejorar la velocidad y la eficiencia del sitio web mediante optimizaciones puntuales: carga diferida de iframes y video, control de scripts innecesarios y limpieza segura de la base de datos. Está pensado para mantener un sitio más rápido sin afectar la experiencia de usuario ni requerir una configuración compleja.

## Lenguaje y stack técnico

- PHP 7.4+
- WordPress 6.0+
- Hooks de carga de scripts y estilos
- JavaScript para lazy load
- CSS para ajustes visuales mínimos
- SQL y limpieza segura de tablas de WordPress
- MySQL para manejo de datos del sitio

## Uso

1. Instalar el plugin en wp-content/plugins/.
2. Activarlo desde la sección de plugins.
3. Entrar al panel del plugin desde el administrador.
4. Configurar:
   - lazy load de video e iframes
   - control de scripts cargados en frontend
   - limpieza de base de datos con opciones cautelosas
5. Aplicar los cambios y comprobar velocidad y rendimiento del sitio.

## Casos de uso

- Sitios con contenido multimedia
- Blogs con carga excesiva de scripts
- Tiendas con rendimiento lento
- Proyectos que necesitan mejoras rápidas y funcionales
